# Space Baby Crawler 🚀👶

A 3D endless runner game where you control a baby crawling through space, collecting milk bottles and avoiding obstacles!

## Features

- 🎮 Simple left/right controls
- 🌌 Beautiful space-themed environment
- 🍼 Collect milk bottles for points
- 🚫 Avoid obstacles to survive
- ⚡ Increasing difficulty over time
- 🎯 Score tracking
- 🔄 Restart functionality

## How to Play

1. Use the LEFT and RIGHT arrow keys to move the baby
2. Collect milk bottles (white spheres) to increase your score
3. Avoid obstacles (red cubes) - hitting them ends the game
4. The game gets progressively faster as you play
5. Try to get the highest score possible!

## Installation

1. Make sure you have [Node.js](https://nodejs.org/) installed
2. Clone this repository
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
5. Open your browser and navigate to `http://localhost:5173`

## Development

The game is built using:
- Three.js for 3D rendering
- Vite for development and building
- Modern JavaScript (ES6+)
